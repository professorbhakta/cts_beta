# Commuter user guide

Short guide for **commuters** using the c2s app.

**Flows:** [FLOWS_BY_ROLE.md](../FLOWS_BY_ROLE.md)

---

## Sign in

1. Open the app
2. Enter mobile and password (account created by admin)
3. Tap **Login** → **Commuter home**

---

## Home screen

<!-- After capture: ![Commuter home](../assets/screenshots/commuter/home.png) -->

- Greeting with your name
- **Today’s date**
- **Coming today** switch — tells transport whether you are riding today

---

## Mark “coming today”

1. Toggle the switch **on** or **off**
2. Read the confirmation dialog
3. Tap **CONFIRM**
4. Wait for “Status updated” (or an error if network failed)

Pull down to **refresh** your profile if data looks wrong.

---

## Menu

Open **☰** for drawer (profile and other items depending on build).

**Logout:** Profile → Logout when you need to switch accounts.

---

## Tips

- Update your status before pickup window your admin communicated
- If update fails, check internet and try again
- Contact your admin office for schedule or route questions — this app only updates your coming status and profile view
