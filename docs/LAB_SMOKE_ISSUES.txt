ISSUE-011 | GOTCHA | STATUS: OPEN
When: 2026-08-29
Where: Agent / adb
What:  Guessed pixel taps miss Flutter controls (user watching). “Blind tap”
       without hierarchy is unreliable on MIUI + tall Pixel skin.
Fix for agents:
  adb shell settings put system show_touches 1
  adb shell settings put system pointer_location 1
  adb shell uiautomator dump /sdcard/ui.xml
  parse content-desc + bounds → tap center
  re-dump after every navigation
Do NOT: hardcode x,y from a previous device density.

       UI stayed on Dashboard).
Workaround: Close drawer (BACK); swipe scroll so tile is mid-screen; tap
       content-desc matching LIVE.*Batch-01; confirm next dump shows “D2D Channel”.

ISSUE-009 | GLITCH | STATUS: OPEN
When: 2026-08-29
Where: OdometerKmSheet (start/end) via adb
What:  Confirm start/end KM while EditText empty → validation “KM is required”.
       adb input text without focusing EditText does nothing useful.
Workaround:
  1. dump → find class=android.widget.EditText bounds
  2. tap center (sometimes double-tap)
  3. keyevent DEL clear if needed
  4. input text <digits>
  5. then tap Confirm start KM / Confirm end KM
Skip path: content-desc “Skip for now” or tooltip Close — leave without record (PASS for soft STOP).

ISSUE-006 | GOTCHA | STATUS: OPEN
When: 2026-08-29
