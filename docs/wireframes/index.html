How this app works

Interactive product demo of the Commuter Transport System. Pick a role to try the real navigation — or start a 2‑minute guided tour.

🛡

Admin

Manage routes, batches, vehicles, and live trips from one dashboard.

  • Dashboard stats & quick actions
  • CRUD lists → forms, delete confirms
  • Running trips → D2D Channel
  • Offline mode & sync banner
🚌

Driver

See today’s assignment and run the door‑to‑door trip log.

  • Assignment card (batch · time · cab)
  • START TRIP → live D2D log
  • Call riders · Stop trip → home
🚶

Commuter

Tell transport if you are riding today — one clear daily action.

  • Greeting + Coming today switch
  • Confirm dialog before save
  • Profile → logout
